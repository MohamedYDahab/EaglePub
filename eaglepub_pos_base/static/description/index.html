EaglePub POS Base

The plumbing the EaglePub point of sale apps share, so each one does not ship its own copy of it.

Install this on its own and nothing changes

That is the point. It exists to be depended on. Install it because an EaglePub app asked for it, or install it first and add the apps you want afterwards - they will all share this one manager PIN and one override group rather than each inventing their own.

What it provides

A manager PIN per point of sale

Checked on the server, and deliberately never loaded into the browser - anything the till loads is readable by whoever stands at it, which would defeat the purpose of having a PIN.

A PIN keypad for the till

A touch-sized dialog that any EaglePub app can raise, so authorising an action looks and behaves the same wherever it happens.

The POS Manager Override group

Supervisors who are Odoo users are waved through without the keypad. Those who are not type the PIN. One group governs every EaglePub app you install.

One hook for developers

askManagerPin(reason) on the POS store returns true once a manager has authorised. Await it before anything you want gated.

Setting the PIN

Settings → Point of Sale → EaglePub → Manager PIN. It is set per point of sale, so pick the right one in the selector at the top of that page.
